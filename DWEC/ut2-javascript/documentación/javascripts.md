# Estructuras

## Arrays
Permite almacenar una colección de datos a los que permite acceder de forma aleatoria

### Métodos

| Método | Descripción |
|--------|-------------|
|        | Añadir un elemento al final |
|        | Añador o eliminar elementos |
|        | Obtener el valor almacenado en una posición |
|        | Ordenar el array |
|        | Buscar un elemento que pasa la prueba |
|        | Comprobar si contiene un elemento |
|        | Conocer la longitud del array |
